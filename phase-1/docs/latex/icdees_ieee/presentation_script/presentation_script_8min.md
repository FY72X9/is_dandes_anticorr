**Slide Visual Elements:**
* **Protocol 1 (Majority Voting):** Orthogonality ($\kappa = 0.041$) causes mutual cancellation, dropping 3,940 local isolates.
* **Protocol 2 (Dual-Path Consensus):** Formula $\text{LOF} \lor (\text{IF} \land \text{RDA})$.
* **Local Channel:** Preserves heavy-tailed density isolates ($BC = 0.957$).
* **Global Channel:** Suppresses single-model noise via dual convergence.

**Spoken Script (Ucapkan Kalimat Ini):**
> "For **Research Question 2**, we compare ensemble architectures.
> 
> Standard majority voting fails because model agreement is near zero—Cohen's Kappa is only **0.041**.
> 
> As a result, majority voting cancels out **3,940 high-risk local outliers**. `[PAUSE]`
> 
> Therefore, we designed **Dual-Path Consensus**.
> 
> Path 1 preserves local LOF density outliers directly.
> 
> Path 2 requires joint agreement between Isolation Forest and the Autoencoder.
> 
> This completely eliminates mutual cancellation."

**Pacing Tips:** Ini adalah kontribusi teoritis terbesar paper Anda. Berikan penekanan suara pada frasa "*cancels out 3,940 high-risk local outliers*".
